# Оптические калькуляторы P.Y.E

Однофайловый инструмент для оптиков: три калькулятора на одной странице с переключением вкладок. Без зависимостей и сборки — открываешь `index.html` в браузере, всё считается на лету.

**Живой сайт:** https://kolyazotovpye.github.io/optics-calc/

## Вкладки

### corPD — призматическое смещение
Пересчёт межцентрового (PD) и высоты (HV) с учётом призмы по правилу **0.25 мм на 1 пр.дптр**.

- Горизонталь: `corPD = Dpp + prism · 0.25 · dir`, где `dir = −1` для BO (base out) и `+1` для BI (base in).
- Вертикаль: `corHV = HV + prism · 0.25 · dir`, где `dir = −1` для BU (base up) и `+1` для BD (base down).
- Результат округляется до 0.5 в сторону исходного значения.
- Если призма < 2.0 пр.дптр — смещением можно пренебречь (подсказка выводится автоматически).

### Транспозиция — пересчёт астигматического рецепта
Перевод записи между плюс- и минус-цилиндром. Оптическая сила линзы не меняется, меняется только запись.

- `SPH_нов = SPH + CYL`
- `CYL_нов = −CYL`
- `AX_нов = AX + 90` если `AX ≤ 90`, иначе `AX − 90` (в диапазоне 0–180°)

Пример: `+1.00 / −2.00 / 90°` → `−1.00 / +2.00 / 180°`.

### Диаметр — минимальный диаметр линзы
Оценка минимального диаметра под оправу с учётом децентрации.

`Диаметр = межцентровое расстояние − межзрачковое расстояние + наибольший размер проёма + 1 мм`

(+1 мм — технологический припуск). На вкладке есть схема оправы с обозначением межцентрового расстояния и наибольшего размера проёма.

## Стек

Чистые HTML + CSS + JS, один файл. Схема оправы — инлайн-SVG. Тёмных зависимостей и трекеров нет.
